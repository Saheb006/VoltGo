# ⚡ VoltGo

**VoltGo** is an EV charging marketplace that connects **EV owners** with **charger owners**. EV owners can discover nearby charging stations, check compatible connectors, compare charging prices, and book charging ports. Charger owners can register their chargers, add charging ports, configure pricing, and manage availability.

## 🚗 EV Owner Features

### 1. Profile Creation & Account

EV owners can create and manage their personal profiles through the **account section**. The profile provides access to account information, activity, vehicle selection, and other user settings.

Users can also manage their account and switch between available account types when required.

### 2. Vehicle Selection

After creating an account, an EV owner can select their vehicle by searching for the **manufacturer and model**.

The selected vehicle helps the platform determine which **charging connectors** are suitable for the EV.

For example, the user can search for a vehicle such as a **Tata, Mahindra, Maruti Suzuki**, or another supported EV model.

### 3. Searching for Chargers

EV owners can search for charging stations using the **interactive map**.

The charging interface allows users to:

- **Search for charging stations**
- **View nearby stations**
- **Filter stations**
- **Check station distance**
- **View available charging ports**
- **Check connector compatibility**
- **Compare charging power and prices**

### 4. Viewing Charger Information

When an EV owner selects a charging station, the application displays the **available ports**.

Each port can show:

- **Connector type**
- **Maximum charging power**
- **Price per kWh**
- **Availability status**

### 5. Booking a Charging Port

After selecting an **available compatible port**, the EV owner can proceed with the booking.

The application displays a **confirmation window** before the booking is completed, allowing the user to confirm or cancel the request.

## ⚡ Charger Owner Features

### 1. Charger Owner Profile Creation

Users who want to provide EV charging services can create a **Charger Owner account**.

This gives them access to **charger-management features** that are different from the EV Owner interface.

The charger owner can manage their **charging infrastructure** from their account.

### 2. Posting a Charger

Charger owners can add their **charging station to VoltGo** so that EV owners can discover it through the charging map.

When creating a charger, the owner can provide information such as:

- **Charger name**
- **Charger location**
- **Address**
- **Number of ports**
- **Charger information**
- **Port configurations**

Once posted, the charger becomes part of the **VoltGo charging marketplace**.

### 3. Adding Charging Ports

A charger can contain **multiple individual charging ports**.

Each port can be configured separately with:

- **Connector Type**
- **Maximum Power (kW)**
- **Price per kWh**
- **Status**
